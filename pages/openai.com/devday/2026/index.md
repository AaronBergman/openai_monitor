### Codex Has Left The Laptop

Explore what’s new in Codex across the CLI, app, and web. Through live demos, see how to move from delegating individual tasks to letting Codex tackle entire problems and goals.

### How OpenAI Puts ChatGPT to Work

See how OpenAI’s teams use ChatGPT to manage launches, research competitors, and turn expertise into tools. Take practical ideas back to your own work.

Find and fix vulnerabilities with OpenAI’s cyber models and open-source CLI and SDK. Learn to scan large codebases, catch issues in pull requests, and verify fixes, drawing on OpenAI’s own security work.

### Building with GPT-Live and Image Generation

See GPT‑Live brainstorm, play games, and create images while coordinating work in the background. Learn to add voice to agents and design for delegation, latency, interruptions, and changing requests.

### Stack Overflow - From Idea to Product

See how small teams at Stack Overflow used Codex to build Stack Overflow for Agents and reimagine Stack Internal. Take away lessons for accelerating R&D and bringing new products to market.

![DevDay 2026 session artwork for Higgsfield — Building Agents That Provision Their Own Compute.](https://images.ctfassets.net/kftzwdyauwt9/5L6aRfy1CbBqotQdSBdNRG/8f69cb3881f91b6eae0e0515a778098c/17___Higgsfield_-_Building_Agents_That_Provision_Their_Own_Compute.png?w=3840&q=90&fm=webp)

### Higgsfield - Building Agents That Provision Their Own Compute

Explore how Higgsfield agents choose models and provision their own compute. Learn when to use dedicated GPUs or hosted models, how to deliver predictable throughput, and where the approach can fail.

![DevDay 2026 session artwork for Stop Overpaying for Intelligence.](https://images.ctfassets.net/kftzwdyauwt9/6TWwe7GdnFDDshCSr2gJQN/adb06e40ddd34dee03d52f2feeba04ef/18___Stop_Overpaying_for_Intelligence.png?w=3840&q=90&fm=webp)

### Stop Overpaying for Intelligence

Cut AI costs while preserving quality. Learn to measure cost per completed task, choose models and reasoning effort, and use prompt caching, Programmatic Tool Calling, and the Batch API.

![DevDay 2026 session artwork for Qodo — The Last Human Code Review.](https://images.ctfassets.net/kftzwdyauwt9/5aTS07N446WCNtZ32TQubV/340b7baa888b7f3a57e4ced8b5472075/19___Qodo_-_The_Last_Human_Code_Review.png?w=3840&q=90&fm=webp)

### Qodo - The Last Human Code Review

See how Qodo uses OpenAI to review AI-generated code. Explore an adversarial reviewer that challenges coding agents’ assumptions and output, and learn when model confidence still needs human judgment.
