# OpenAI to acquire Pierre Computer Company, Inc.

Expanding Codex’s tools for building, understanding, and reviewing code.

Today we're announcing that OpenAI will acquire [_Pierre Computer Company, Inc_ ⁠(opens in a new window)](<https://pierre.computer/>). (“Pierre”), the company behind [_Code Storage_ ⁠(opens in a new window)](<https://code.storage/>) and a family of standout open-source developer tools. If you’ve browsed files or reviewed a change in the Codex app, you’ve already used Pierre’s Trees and Diffs libraries. We’re excited to work with the Pierre team to build on the Git workflows that developers already rely on and adapt them to how teams work with coding agents.

We’ve seen in our own engineering work how the systems around Git need to evolve as more of that work happens in parallel. Earlier this week, we shared how we’re [_scaling Git at OpenAI_](</index/scaling-git-at-openai/>) with Pando, our in-house source control backend for engineers and agents. With the Pierre team, we wish to set the standard for modern software development: from the first branch an agent creates to that magic moment when code is deployed to the world. We want to make Codex the place where developers and agents take on their most ambitious projects.

## Craftsmanship meets scale for the agentic era 

We’ve long appreciated the care Pierre brings to another part of working with Git: how developers review code. You can see that care in the libraries we use in Codex today. Trees lets developers quickly navigate a project’s files, and Diffs makes it easy to see what changed. Both of these tools make it easy to review and navigate large volumes of code with uncompromising performance. 

That same attention to detail runs through Pierre’s other work. Diffs’ _Edit_ mode lets a reviewer fix a line of code right where they spot the problem. Pierre recently released _Highlights_ , an extremely fast syntax highlighter that updates as a developer types or an agent streams code. The same small team that put an editor inside a diff also designed the API for Code Storage, a service that lets apps store code and track its history using Git.

## Bringing the work together in Codex

Pierre has built tools that developers love, and together, we will ship new products and platforms that benefit all. Once the acquisition closes, our ambition is to advance the future of source control across the industry. We want Codex to connect the code a company ships with the decisions its people make, at the scale the future demands.

Pierre’s open-source projects will remain open-source, and we’ll continue to contribute to them. Customers can continue using Code Storage after the acquisition closes while we work to bring its features and functionality into Codex.

_The closing of the acquisition is subject to customary closing conditions, including receipt of regulatory approvals. Until closing, OpenAI and Pierre will remain separate and independent companies._
