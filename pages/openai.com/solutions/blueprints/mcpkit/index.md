# Build authenticated MCP servers for your data

MCPKit provides a sample repo that helps teams safely connect data with ChatGPT or other MCP clients.

[Talk to an expert](</contact-sales/>)[Get started(opens in a new window)](<https://github.com/openai/openai-mcpkit>)

![Chat interface showing an order status request for EC-100045 and detailed order overview with customer, service, warehouse, and tracking information.](https://images.ctfassets.net/kftzwdyauwt9/32pPkcgREk7u8dm2KjhzDr/b0e687358bb062b3d552f4ce2740bfc4/MCPKit_Hero.png?w=3840&q=90&fm=webp)

### A reliable foundation for MCP development

With MCPKit, you can quickly create new connections to ChatGPT with a secure, consistent setup.

#### Start with a proven foundation 

Use a reference implementation aligned with the official MCP spec to build with confidence.

#### Control data access

Custom authentication and access following recommended MCP authorization specifications.

![Dark-themed ChatGPT logo on a gradient background.](https://images.ctfassets.net/kftzwdyauwt9/2zExoSxSjxmvtnteSPGixq/b5a483e440fe6c806bfab16405c5e976/chatgpt.svg?w=3840&q=90)

#### Connect to ChatGPT

Optimized for use with ChatGPT through custom apps and developer mode.

### Launch production-ready apps

Access the repo and reference architecture, then follow these three steps to get started.

[View repo(opens in a new window)](<https://github.com/openai/openai-mcpkit>)

![Grid of six rounded icons on a blue gradient background, representing document, table, database, globe, folder, and code symbols.](https://images.ctfassets.net/kftzwdyauwt9/2U9on9tqRrAD1noZPiF2V/0d4514ba70d67e3ceb077be685079a8e/Prepage_Your_Data.png?w=3840&q=90&fm=webp)

### Prepare your data source

Structure and index your data—vector stores, files, databases, S3, or APIs—and define query access rules.

![Code editor showing a Python async function decorated with @mcp.tool\(\) defining order_status_lookup with parameters for order ID, customer ID, and tracking number.](https://images.ctfassets.net/kftzwdyauwt9/5EY59jHyaR0PsromRUA9fx/774e859419f3b5263f8696999571633b/Configure_the_MCP_server.png?w=3840&q=90&fm=webp)

### Configure the MCP server

Clone the repo, add entitlements, and update tool actions and error handling.

![Form interface labeled New Connector for configuring an MCP connection named Order Management MCP, including description, server URL, and OAuth authentication.](https://images.ctfassets.net/kftzwdyauwt9/6okcZkmKUAmRNlkU1FPxh2/e9c40c0917b12cf8723925e3a35f9038/Validate_and_deploy.png?w=3840&q=90&fm=webp)

### Validate and deploy

Test locally with MCP Inspector, then register your app in ChatGPT with Dev Mode.
