## Decisions API with GPT-6 Luna is now generally available

The Decisions API is now generally available with `gpt-6-luna`. Cache shared input across requests for prompt-cache discounts, include images in individual question instructions, and pass structured data directly with `input_json`. Each request now supports up to 400 questions, increased from 200 in public beta.

[View source(opens in a new window)](<https://developers.openai.com/api/docs/guides/decisions>)[Platform docs(opens in a new window)](<https://developers.openai.com/api/docs/changelog#october-2026>)

Oct 22, 2026

GA

## Share profiles within your Enterprise workspace

Enterprise workspace members can share their profiles with coworkers, including activity and Sites they choose to showcase. Workspace owners control whether profiles and activity are available and whether profiles are visible only to their owners or to other workspace members.

Shared Enterprise profiles are limited to members of the same workspace. Adding a Site to a profile does not change who can access that Site. Shared profiles do not show conversation titles or content.

[View source(opens in a new window)](<https://help.openai.com/en/articles/10128477-chatgpt-enterprise-and-edu-release-notes#share-profiles-within-your-enterprise-workspace>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/20001539-shareable-profiles-in-chatgpt>)

ChatGPT

Oct 21, 2026

GA

## Manage Business workspace settings in Admin Console

In addition to Workspace settings in ChatGPT, workspace owners and admins can manage members and available Business workspace controls in Admin Console. Select your Business workspace. For some workspaces, selecting Workspace settings automatically opens Admin Console.

Your workspace role and plan permissions still apply. Using Admin Console does not add Enterprise-only features or change who can manage paid seats.

[View source(opens in a new window)](<https://help.openai.com/en/articles/11391654-chatgpt-business-release-notes#manage-business-workspace-settings-in-admin-console>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/8542216-managing-members-seat-types-and-roles-in-chatgpt-business>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/12289294-managing-your-tenant-in-admin-console>)

API

Oct 20, 2026

GA

## 12-hour prompt caching in the API

You can now choose 12-hour prompt caching in the API. 12-hour prompt caching keeps shared instructions, tools, and context cached longer to benefit from lower cached-input pricing, even when requests are hours apart. 12-hour cache writes cost 2.5x the input token price.

[View source(opens in a new window)](<https://developers.openai.com/api/docs/guides/prompt-caching>)[Platform docs(opens in a new window)](<https://developers.openai.com/api/docs/changelog#october-2026>)
