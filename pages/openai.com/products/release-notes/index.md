## Manage Business workspace settings in Admin Console

In addition to Workspace settings in ChatGPT, workspace owners and admins can manage members and available Business workspace controls in Admin Console. Select your Business workspace. For some workspaces, selecting Workspace settings automatically opens Admin Console.

Your workspace role and plan permissions still apply. Using Admin Console does not add Enterprise-only features or change who can manage paid seats.

[View source(opens in a new window)](<https://help.openai.com/en/articles/11391654-chatgpt-business-release-notes#manage-business-workspace-settings-in-admin-console>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/8542216-managing-members-seat-types-and-roles-in-chatgpt-business>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/12289294-managing-your-tenant-in-admin-console>)

Oct 20, 2026

GA

## 12-hour prompt caching in the API

You can now choose 12-hour prompt caching in the API. 12-hour prompt caching keeps shared instructions, tools, and context cached longer to benefit from lower cached-input pricing, even when requests are hours apart. 12-hour cache writes cost 2.5x the input token price.

[View source(opens in a new window)](<https://developers.openai.com/api/docs/guides/prompt-caching>)[Platform docs(opens in a new window)](<https://developers.openai.com/api/docs/changelog#october-2026>)

ChatGPT

Oct 20, 2026

GA

## Introducing locked chats

Locked chats let you keep selected conversations in your account while hiding them from regular chat history, pinned chats, and search without deleting them. Open them with your 4-digit account PIN or supported device authentication. Your retention and model-improvement settings stay unchanged.

Locked chats are rolling out gradually to Free, Go, Plus, Pro, Business, Enterprise, and Edu users on the web, in the iOS and Android apps, and in the new ChatGPT desktop app for macOS and Windows. To lock a chat, open a chat’s more options menu (•••) and select Lock chat.

Workspace policies and retention settings stay unchanged. Your organization’s retention policies and compliance requirements still apply. Locked chats remain included in conversation message logs available through the OpenAI Compliance Platform.

[View source(opens in a new window)](<https://help.openai.com/en/articles/6825453-chatgpt-release-notes#introducing-locked-chats>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/11391654-chatgpt-business-release-notes#introducing-locked-chats>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/10128477-chatgpt-enterprise-and-edu-release-notes#introducing-locked-chats>)

API

Oct 16, 2026

GA

## Prompt-to-voice and nine new GPT-Live voices

Released prompt-to-voice for all API customers. Create a custom voice from a text description through the API or voice Playground, then reuse it in GPT‑Live sessions. Creating a prompt-generated voice is free; speech generation uses regular GPT‑Live session billing.

Added nine natural voices for GPT‑Live: Nuri, Juni, and Flitz (German); Brise and Sillage (French); Nira (Hindi); Harema and Shida (Japanese); and Noeul (Korean).

[View source(opens in a new window)](<https://developers.openai.com/api/docs/guides/custom-voices>)[Platform docs(opens in a new window)](<https://developers.openai.com/api/docs/guides/live-conversations>)[Platform docs(opens in a new window)](<https://developers.openai.com/api/docs/changelog#october-2026>)
