## Composer predictions in Codex

Composer predictions, available in beta, suggest your next message based on the conversation in your current Codex thread. After Codex responds, a suggestion may appear in the message box. Press Tab to accept it, then review or edit it before sending. Accepting a suggestion doesn’t send it automatically.

The beta is available to personal ChatGPT Pro users aged 18 and older in all supported regions, in the latest Codex desktop app. It supports local and SSH threads using GPT‑6 Astra or GPT‑6.1 Sol. Predictions are on by default; turn off Show predictions in the Composer section of General settings. During the beta, generating predictions doesn’t count toward Codex usage limits or consume credits. Messages you send, including accepted predictions, follow normal Codex usage limits and billing.

[View source(opens in a new window)](<https://help.openai.com/en/articles/6825453-chatgpt-release-notes#composer-predictions-in-codex>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/20001601-composer-predictions-in-codex>)

## Ultrafast mode for GPT-6.1 Sol

Added Ultrafast mode for GPT‑6.1 Sol in the Responses API. Use `gpt-6.1-sol` with `service_tier: "ultrafast"` to reduce the time between generated output tokens. It is available to all API users, subject to rate limits, with global processing and US and EU data residency.

[View source(opens in a new window)](<https://developers.openai.com/api/docs/guides/ultrafast-mode>)[Platform docs(opens in a new window)](<https://developers.openai.com/api/docs/models/gpt-6.1-sol>)[Platform docs(opens in a new window)](<https://developers.openai.com/api/docs/pricing?latest-pricing=ultrafast>)

## Faster steering in Codex

We’re rolling out faster steering in Codex in the ChatGPT desktop app. When you send a follow-up to steer a running task, Codex can respond to your changes sooner.

Use steering to correct an approach, add missing information, or change direction while Codex works. You can choose whether follow-up messages steer the current run or wait for the next one in Settings → General → Follow-up behavior.

[View source(opens in a new window)](<https://help.openai.com/en/articles/6825453-chatgpt-release-notes#faster-steering-in-codex>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan>)

Oct 8, 2026

GA

## Manage plugin access by role

Workspace owners and admins in ChatGPT Enterprise and Edu workspaces with RBAC enabled can now manage plugin access by role. Set the workspace default to Available, Install, or Disabled. Custom roles can use those settings or Default to inherit the workspace setting.

In the Admin console, select the ChatGPT workspace, open Plugins, and select a plugin. Review and save plugin access and the corresponding required-app permissions together. App action settings, approval requirements, and provider authorization continue to apply.

[View source(opens in a new window)](<https://help.openai.com/en/articles/10128477-chatgpt-enterprise-and-edu-release-notes#manage-plugin-access-by-role>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/11509118-admin-controls-security-and-compliance-for-plugins-and-apps>)[Help center(opens in a new window)](<https://help.openai.com/en/articles/11750701-managing-feature-access-with-role-based-access-control-in-chatgpt>)

## Updated chat-latest model snapshot

Updated the chat-latest snapshot, which points to the latest model available in ChatGPT for Plus, Pro, Business and Enterprise users. We recommend leveraging the GPT‑6 model family for production API usage, but feel free to use this model to test the latest improvements for chat use cases.
