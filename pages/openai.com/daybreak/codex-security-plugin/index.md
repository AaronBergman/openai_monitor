Step 1

### Install Codex

If Codex is already installed and you’re signed in, skip to the next step.

[Install Codex(opens in a new window)](<https://developers.openai.com/codex/quickstart?setup=app>)

![Daybreak plugin card with the Add plugin button highlighted.](https://images.ctfassets.net/kftzwdyauwt9/7lwprY1UDFl1cbNiICKnK5/c0f32d8f52fe4c1961e8793a494f1e17/daybreak-plugin-quickstart-add-plugin.png?w=3840&q=90&fm=webp)

Step 2

### Add the Daybreak plugin

Add the plugin in Codex. After installation is complete, the button changes to “Try in chat.”

[Add the Daybreak plugin(opens in a new window)](<https://chatgpt.com/plugins/share/676aca3811d54fa7bcdef5255236b3c4>)

![Daybreak plugin shown as installed with a checkmark.](https://images.ctfassets.net/kftzwdyauwt9/5W0w5l9cE78itUKk60R0hJ/c8b06a68e9289ab2bebcda0caf58ce31/daybreak-plugin-quickstart-installed.png?w=3840&q=90&fm=webp)

Step 3

### Click “Try in chat”

This starts a new Codex chat with a Daybreak scan prompt ready to run.

![Codex chat composer prefilled with a Daybreak scan prompt.](https://images.ctfassets.net/kftzwdyauwt9/1EQwOAx85eK9jQ2UutlZJE/73929dc3260157b9a2a36079e9c95db8/daybreak-plugin-quickstart-prompt.png?w=3840&q=90&fm=webp)

Step 4

### Pick a project folder

Choose a folder that contains the code you want Daybreak to review.

![Project picker showing a project called Repository selected in Codex.](https://images.ctfassets.net/kftzwdyauwt9/3Ck3ewHlkJLXnOi1IepUlb/b67f06389fe720235d0ceb9d77ded35c/select_folder__1_.png?w=3840&q=90&fm=webp)

Step 5

### Send the scan prompt

Codex opens with the Daybreak scan prompt ready. Press “Send” to start the scan.

![Codex composer send button highlighted to run the scan.](https://images.ctfassets.net/kftzwdyauwt9/4P7SG5JP5vY2ebj2wuahpb/19c1ec71f313f3b3d3d840420a142ee0/run_scan.png?w=3840&q=90&fm=webp)
