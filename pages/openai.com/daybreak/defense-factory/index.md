# Turn your security backlog into fixes

Put AI agents to work investigating vulnerabilities and preparing patches for review.

[Contact sales](</daybreak/contact-cyber-sales/>)[Documentation(opens in a new window)](<https://learn.chatgpt.com/docs/security/setup>)

### Give engineers a fix they can act on

Agents trace vulnerabilities through your code and develop patches. Engineers review and test proposed patches before merge.

![Proposed code changes displayed as a diff in Daybreak Defense Factory.](https://images.ctfassets.net/kftzwdyauwt9/37Tsppz7FMOaVvr59KMApx/058847d8f0ac2cd1d77c36206feccabe/daybreak-defense-factory-proposed-changes-2x.png?w=3840&q=90&fm=webp)

![Security dashboard showing open findings by severity, fixed findings, and finding status.](https://images.ctfassets.net/kftzwdyauwt9/3l9K8ymeEQY2Y23RnPLmLN/65bfeaeb4149b4f4ffe30643ba7d9231/daybreak-defense-factory-security-dashboard-2x.png?w=3840&q=90&fm=webp)

### Put your existing security tools to work on fixes

Bring findings from your security tools and Daybreak Red Team into the Defense Factory. Agents investigate each issue and develop a fix.

### Work directly with Codex on the fix

Add context, examine evidence, and tune a patch with Codex. Test the changes while agents continue working in the background.

![A vulnerability finding with investigation evidence, a potential fix, and a Fix with Codex action.](https://images.ctfassets.net/kftzwdyauwt9/7uZ2QZf94T1Ync38dj1TZI/d281b208e0c3b4f7892e5609d3fb1ef7/daybreak-defense-factory-finding-details-2x.png?w=3840&q=90&fm=webp)

![Scan history listing recurring monitoring and pull request scans with their status and findings.](https://images.ctfassets.net/kftzwdyauwt9/5uIczm6ysPQLfyr9JXiltm/5458195cda6cefd3712a668063391f50/daybreak-defense-factory-scan-history-2x.png?w=3840&q=90&fm=webp)

### Make finding and fixing continuous

Scan new commits or schedule recurring checks as your code changes. Put agents to work investigating new findings.
