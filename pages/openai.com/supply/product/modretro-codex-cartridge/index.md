# ModRetro Codex Cartridge

$50.00

Another cartridge. Another world to build. Get an extra programmable Codex Cartridge, exclusively from Supply Co., for whatever you create next.

Comes with a Codex Charm. 

Restock soon

Expected restock: November 19

## Specifications

  * Programmable cartridge

  * Supports original Game Boy® and Game Boy Color® (.gb / .gbc)

  * Includes activation code to enable Chromatic Developer-Mode on your computer

  * Activation code limited to two devices, exclusive to the ModRetro Chromatic: Codex Edition

  * Use ModRetro Chromatic Plugin to create your own game, flash it onto your Codex Cartridge

  * Before cartridge play: update your firmware and activate Developer-Mode
