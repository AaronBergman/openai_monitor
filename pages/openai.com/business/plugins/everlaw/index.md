## How it works

Connect ChatGPT to live matter data in Everlaw to search, retrieve, and analyze evidence using natural language. Everlaw’s Model Context Protocol (MCP) server authenticates and authorizes each request against your existing permissions, limiting access to the projects, documents, and data you can already view. Understand your project structure and turn natural-language requests into structured Everlaw searches. Search by document text, metadata, Bates or Control number, binder, coding, redactions, productions, processing criteria, and other supported terms. Identify the metadata fields, datasets, and processed uploads available in a project. Retrieve matching documents with Bates numbers, metadata, review links, document-text links, and extracted values. Generate structured reports on project contents, document volumes, custodians, dates, Bates ranges, and other returned data. Summarize and analyze retrieved documents or result sets in natural language. Once Deep Dive tools are available through the connector, ask broader investigative and semantic questions over eligible project data and receive evidence-backed results. This complements Everlaw’s search and retrieval tools and native Deep Dive experience while preserving permissions and the underlying matter record. Everlaw remains the governed system of record for case materials, metadata, and work product.
