## How it works

Answer "what do I need from my IT team to run this on Notable?" using Notable's published integration documentation. Built for health system IT, interface analysts, network and telecom teams evaluating or implementing Notable. What it covers: \- HL7 v2 message specifications for ADT, DFT, MDM, ORM, ORU, and SIU \- Connectivity setup: site-to-site VPN, SFTP, SAML SSO, and DNS \- Telephony integration options and the telephony checklist \- X12 278 enablement overview \- Integration prerequisites and readiness checklist It can also draft an integration readiness checklist for your workflow, with each requirement linked to the public documentation page it comes from. Limitations: it uses only Notable's public integration documentation. It does not connect to your EHR or to any Notable environment, and it cannot see your organization's configuration. Do not share patient information. The plugin does not need it and will not process it.
