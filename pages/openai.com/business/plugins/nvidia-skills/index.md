## How it works

Find and install the right NVIDIA skill for work across GPU acceleration, CUDA, AI agents, data loading, training, inference, robotics, Physical AI, Omniverse, simulation, and more. The plugin checks NVIDIA's live skills catalog, recommends the best match, and provides an install command and a useful first prompt.
