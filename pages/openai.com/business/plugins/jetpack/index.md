## How it works

Connect your WordPress site to ChatGPT with Jetpack AI. Publish and update content, manage plugins and settings, and work through routine admin without jumping into WordPress for every change. Jetpack’s ChatGPT plugin uses the full WordPress.com MCP toolkit. Requires the Jetpack plugin to be active, and MCP access enabled for the site.
