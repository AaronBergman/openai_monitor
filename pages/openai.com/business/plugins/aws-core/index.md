## How it works

Includes the AWS MCP Server configuration and default skills for common AWS workflows. Covered domains include service selection, infrastructure as code (CDK and CloudFormation), serverless, containers, databases, storage, observability, billing, SDK usage, and deployment. We recommend this plugin for all AWS developers.
