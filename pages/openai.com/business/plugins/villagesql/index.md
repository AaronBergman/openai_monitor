## How it works

Skills for VillageSQL including building extensions from scratch and porting PostgreSQL extensions to VillageSQL.

### Standardize product codes

Build a VillageSQL extension that normalizes product codes consistently for catalog joins.

### Port a PostgreSQL extension

Adapt an existing PostgreSQL extension to VillageSQL with tested behavior and documented compatibility gaps.

### Validate package dimensions

Create a custom VillageSQL type that validates package dimensions and exposes a volume function for shipping queries.

## Sample prompts

**@VillageSQL** Build an extension with a function that normalizes our product codes using the attached rules. Define invalid-input behavior, implement it in C++, and deliver SQL tests and usage examples for catalog joins.

**@VillageSQL** Port this PostgreSQL text-similarity extension to VillageSQL. Assess supported functions first, implement the feasible subset, and deliver SQL comparison tests plus a concise list of compatibility gaps.

**@VillageSQL** Build a custom package-dimensions type for our shipping database, storing centimeters and rejecting zero or negative dimensions. Add a volume function, SQL tests for invalid inputs, and a sample packing query.
