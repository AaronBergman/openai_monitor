**Daybreak** is OpenAI's new cybersecurity product, described as "frontier AI for cyber defenders." It combines OpenAI models, Codex as an agentic harness, and security industry partners to provide:
- Secure code review, threat modeling, patch validation
- Dependency risk analysis, detection, and remediation guidance
- Agentic integration into the software development loop

The product introduces three access tiers using **GPT-5.5**:
1. **GPT-5.5 (default)** — standard safeguards for general-purpose use
2. **GPT-5.5 with Trusted Access for Cyber** — more precise safeguards for verified defensive work (secure code review, malware analysis, detection engineering, patch validation)

This is a significant move: OpenAI is directly entering the enterprise cybersecurity software market with a branded product, not just offering API access. It connects to the earlier "Trusted Access for Cyber" initiative (Feb 2026) and the GPT-5.5-Cyber model launch (May 7, 2026).

### 3. Signals Q1 2026 ChatGPT Adoption Research

- **`/signals/research/2026q1-update/`** (lastmod: 2026-05-12T09:15Z) — [pages/openai.com/signals/research/2026q1-update/index.md](../../pages/openai.com/signals/research/2026q1-update/index.md)

OpenAI's economic research arm ("Signals") published Q1 2026 consumer ChatGPT adoption data. Key findings:
- **Gender**: Users with typically feminine names now account for over half of gender-inferable users — reaching approximate parity last year and now surpassing it.
- **Age**: Users over 35 gained share in Q1 2026, while under-35 users still dominate total messages.
- **Geography**: Fastest-growing countries by per-capita messages include Dominican Republic (+9 ranks), Haiti (+9), Japan (+8), Mexico (+6), Tanzania (+6) — showing broadening beyond established Western markets.
- **Workplace use**: Content creation still leads but is declining as share; health-related documentation and information retrieval are the fastest-growing work tasks on consumer accounts.
